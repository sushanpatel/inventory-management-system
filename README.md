# Inventory Management System

## Overview

The Inventory Management System is a full-stack web application developed to help users manage, track, and update inventory through a centralized system.

The application began as a collaborative university software development project. As the project progressed, I took on expanded responsibilities across frontend and backend development, database implementation, authentication, API functionality, testing, debugging, and technical documentation.

This repository serves as a portfolio case study documenting the project, my technical contributions, and the development and testing experience gained throughout the project.

## Technical Snapshot

**Frontend:** React.js, JavaScript, HTML, CSS  
**Backend & APIs:** JavaScript, REST APIs  
**Database:** MongoDB  
**Authentication:** Firebase Authentication  
**Testing & QA:** Postman, functional testing, frontend testing, API testing  
**Development Tools:** Git, GitHub, Jira  

---

## Key Features

- Inventory item creation, updating, removal, and viewing
- Inventory search and tracking
- User registration and login
- Firebase-based user authentication
- MongoDB database integration
- Frontend-to-backend API communication
- UPC/barcode functionality for inventory items
- Staff management functionality
- Warehouse management
- Product and warehouse relationships
- Sales and purchase order workflows
- Dashboard and reporting functionality
- Functional and API testing

## My Role & Contributions

### Full-Stack Development

Although the application began as a team project, my responsibilities expanded significantly as development progressed.

I worked across both the frontend and backend, modifying existing functionality, troubleshooting issues, implementing improvements, and helping bring the application to its final working state.

My development work included:

- Frontend development and modification
- Backend development and modification
- API integration and troubleshooting
- Database integration
- Application debugging
- Feature testing and improvement
- Resolving issues across frontend/backend communication

### MongoDB Database

The project initially considered Microsoft Azure for database implementation. During later development, I implemented MongoDB as the database solution for the application.

My database work included:

- Building and configuring the MongoDB database
- Connecting application functionality with stored inventory data
- Supporting inventory-related data operations
- Troubleshooting database and application integration

### Authentication

I worked with Firebase Authentication to support user registration, login, and credential authentication.

This provided the application with a structured authentication process for user access.

### REST API Integration

I worked with APIs connecting the frontend, backend, authentication, and database components of the system.

This included testing endpoints, identifying integration problems, and troubleshooting application functionality.

### UPC / Barcode Functionality

I worked on UPC/barcode functionality to support inventory identification and management.

This functionality allowed inventory items to be associated with barcode-based information as part of the application's inventory workflow.
