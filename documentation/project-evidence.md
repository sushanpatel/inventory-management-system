# Project Evidence

## Overview

This page organizes supporting evidence from the Inventory Management System project and connects the technical work described throughout this portfolio with the development, testing, sprint, and project documentation produced during the project.

The Inventory Management System originated as a collaborative university software development project. As development progressed, my responsibilities expanded across frontend and backend development, database implementation, authentication, API functionality, testing, debugging, and technical documentation.

This portfolio repository documents my individual contributions and project experience without reproducing the original team source code.

---

## Evidence Categories

### Full-Stack Development

Project work included contributions across both frontend and backend components of the application.

Documented development experience includes:

- Frontend development and modification
- Backend development and modification
- Application functionality improvements
- Troubleshooting across application components
- Integration between frontend, backend, database, and authentication services
- Debugging and verification of application behavior

The project required working across multiple parts of the system rather than focusing on a single application layer.

---

### Database Implementation

During later development, I implemented MongoDB as the database solution used for the application.

Database-related work included:

- MongoDB database configuration
- Inventory data management
- Application-to-database integration
- Supporting inventory-related data operations
- Troubleshooting database integration

The project had previously considered Microsoft Azure for database implementation before MongoDB became the database solution used during later development.

---

### Authentication

Firebase Authentication was used to support application user authentication.

My work included:

- User registration functionality
- Login functionality
- Credential authentication
- Authentication-related testing
- Validation testing
- Troubleshooting authentication behavior

Authentication workflows were also included in the project's final testing.

---

### REST API Work

The application used REST APIs to support communication between application components.

My API-related work included:

- API integration
- Backend endpoint testing
- Request and response evaluation
- Application communication troubleshooting
- Functional verification
- Postman testing
- Identification of API-related issues

Backend API testing became one of the specific testing responsibilities documented during the project.

---

### UPC / Barcode Functionality

I worked with UPC/barcode functionality used for inventory identification and management.

This work connected barcode-based information with inventory workflows and was included as part of application development and testing.
